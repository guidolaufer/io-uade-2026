🎯 ¿Qué es la Programación Lineal?

Imaginate que tenés una fábrica. Podés fabricar 2 productos, pero no tenés recursos infinitos: hay límite de materia prima, horas de trabajo, espacio. La Programación Lineal (PL) es una herramienta matemática para decidir cuánto producir de cada cosa para maximizar ganancias (o minimizar costos) respetando esos límites.

Analogía: Es como preparar la mejor combinación de platos con los ingredientes que te quedan en la heladera, donde cada plato te da diferente "satisfacción" y usa distinta cantidad de cada ingrediente.
1
Variables de Decisión Son las "incógnitas": ¿cuánto producir de cada producto? Las llamamos x₁, x₂, etc. Siempre son ≥ 0 (no podés producir cantidad negativa).
2
Función Objetivo (FO) Es lo que querés optimizar: MAX Z = ganancia total, o MIN Z = costo total. Es una función lineal de las variables: Z = c₁x₁ + c₂x₂
3
Restricciones Son los límites de recursos. Cada restricción es una inecuación lineal. Ej: 3x₁ + 5x₂ ≤ 100 (la materia prima disponible es 100 kg).
4
Variables de Holgura Al resolver, agregamos una variable "s" a cada restricción ≤ para convertirla en igualdad: 3x₁ + 5x₂ + s = 100. La holgura s dice cuánto recurso sobra.
5
Resolución Gráfica Con 2 variables, graficamos las restricciones como rectas. La región factible es el área que cumple TODAS. El óptimo está siempre en un vértice de esa región.
Regla de oro: El óptimo de un problema de PL siempre está en un vértice (punto extremo) de la región factible. Solo necesitás evaluar la FO en los vértices y elegir el mayor (MAX) o menor (MIN).
TP1 — Ej. 2

Producción de Piezas Metalúrgicas (A y B)

Enunciado completo: Una metalúrgica fabrica piezas tipo A y B. Ambas pasan por Estampado, Soldado y Pintado. Los tiempos de proceso (en segundos/pieza) y disponibilidades son:

OperaciónPieza A (seg)Pieza B (seg)Disponible (seg)
Estampado10015012.000
Soldado120809.600
Pintado60605.400

Beneficio: $80 por pieza A y $60 por pieza B. Objetivo: maximizar beneficio total.

📝 Paso a Paso

1
Definir Variables x₁ = cantidad de piezas A a fabricar (unidades)
x₂ = cantidad de piezas B a fabricar (unidades)
Siempre ponemos la unidad. Así después interpretamos bien la solución.
2
Función Objetivo Queremos maximizar el beneficio total:
MAX Z = 80x₁ + 60x₂
3
Escribir las Restricciones Una por cada recurso limitado:
Estampado: 100x₁ + 150x₂ ≤ 12.000 Soldado: 120x₁ + 80x₂ ≤ 9.600 Pintado: 60x₁ + 60x₂ ≤ 5.400 No neg.: x₁, x₂ ≥ 0
¿Por qué el estampado es 100 para A? Porque fabricar UNA pieza A requiere estampar DOS partes (la pieza se forma soldando dos partes iguales). Por eso el tiempo es el doble del de una parte sola.
4
Simplificar (opcional pero útil) Dividimos todo por 60 en Pintado: x₁ + x₂ ≤ 90
Dividimos Estampado por 50: 2x₁ + 3x₂ ≤ 240
Dividimos Soldado por 40: 3x₁ + 2x₂ ≤ 240
5
Graficar las Restricciones Para cada restricción, encontramos los interceptos (cuando x₁=0 y cuando x₂=0):
Restricciónx₁=0 → x₂=x₂=0 → x₁=
Estampado (÷50)x₂ = 80x₁ = 120
Soldado (÷40)x₂ = 120x₁ = 80
Pintado (÷60)x₂ = 90x₁ = 90
6
Encontrar los Vértices Los vértices son las intersecciones de las rectas activas. Resolvemos sistemas de 2 ecuaciones:
Vértice: Estampado ∩ Soldado
2x₁ + 3x₂ = 240  ...(1)
3x₁ + 2x₂ = 240  ...(2)
(1)×3: 6x₁ + 9x₂ = 720
(2)×2: 6x₁ + 4x₂ = 480
Restando: 5x₂ = 240 → x₂ = 48
En (1): 2x₁ + 144 = 240 → x₁ = 48
Verificar Pintado: 48+48=96 > 90 ❌ No factible
Vértice: Estampado ∩ Pintado
2x₁ + 3x₂ = 240  ...(1)
x₁ + x₂ = 90 → x₁ = 90-x₂  ...(2)
2(90-x₂) + 3x₂ = 240
180 + x₂ = 240 → x₂ = 60, x₁ = 30
Verificar Soldado: 3(30)+2(60)=90+120=210 ≤ 240 ✅
Vértice: Soldado ∩ Pintado
3x₁ + 2x₂ = 240  ...(1)
x₁ + x₂ = 90 → x₁ = 90-x₂  ...(2)
3(90-x₂) + 2x₂ = 240
270 - x₂ = 240 → x₂ = 30, x₁ = 60
Verificar Estampado: 2(60)+3(30)=120+90=210 ≤ 240 ✅
7
Evaluar Z en cada Vértice Factible
Vérticex₁x₂Z = 80x₁ + 60x₂

8
Interpretar la Solución
✅ Solución Óptima:
Producir 60 piezas A y 30 piezas B
Beneficio Máximo = $6.600

Holguras:
• Estampado: 2(60)+3(30) = 210 seg → sobran 240−210 = 30 seg
• Soldado: 3(60)+2(30) = 240 → holgura = 0 (recurso saturado)
• Pintado: 60+30 = 90 → holgura = 0 (recurso saturado)
⚠️ Hay dos vértices con Z=$5.400: (0,90) y (30,60). Eso significa que hay solución múltiple en ese segmento, pero no es el óptimo.

Cerveza BIER S.A.

Enunciado: BIER S.A. fabrica cerveza Negra ($13/barril) y Blanca ($23/barril). Materias primas disponibles: Maíz 480 kg, Lúpulo 160 unid., Malta 1190 kg.

MPNegra (x₁)Blanca (x₂)Disponible
Maíz (kg)515480
Lúpulo (u)44160
Malta (kg)35201190
1
Modelo Matemático
Variables: x₁ = barriles de Negra, x₂ = barriles de Blanca MAX Z = 13x₁ + 23x₂ Sujeto a: 5x₁ + 15x₂ ≤ 480 (Maíz) 4x₁ + 4x₂ ≤ 160 (Lúpulo) → simplificamos: x₁ + x₂ ≤ 40 35x₁ + 20x₂ ≤ 1190 (Malta) x₁, x₂ ≥ 0
2
Interceptos de cada recta
Restricciónx₁=0 → x₂x₂=0 → x₁
Maíz (÷5)x₂ = 32x₁ = 96
Lúpulo (÷4)x₂ = 40x₁ = 40
Malta (÷5)x₂ = 59.5x₁ = 34
3
Vértice clave: Lúpulo ∩ Malta
x₁ + x₂ = 40  ...(Lúpulo simplificada)
35x₁ + 20x₂ = 1190  ...(Malta)

De (L): x₁ = 40 − x₂
35(40−x₂) + 20x₂ = 1190
1400 − 35x₂ + 20x₂ = 1190
−15x₂ = −210
x₂ = 14 barriles de Blanca
x₁ = 40 − 14 = 26 barriles de Negra

Verificar Maíz: 5(26)+15(14) = 130+210 = 340 ≤ 480 ✅
4
Evaluar todos los vértices
Vérticex₁x₂Z = 13x₁+23x₂
Origen000
Eje x₂ (Maíz)032$736
Maíz ∩ Lúpulo≈24≈16≈$680
Lúpulo ∩ Malta ★2614$660
Eje x₁ (Malta)340$442
✅ Óptimo: 26 barriles Negra + 14 barriles Blanca = Z = $660
5
Respuesta a preguntas del TP
¿Qué pasa si disponemos de 100 kg más de Malta?
Nuevo RHS Malta = 1290. Hay que resolver el nuevo sistema Lúpulo∩Malta con el RHS actualizado. Como Malta tiene Shadow Price > 0 (está activa), el nuevo Z será mayor: Z_nuevo = 660 + SP_malta × 100.
¿Y si solo hay 1.000 kg de Malta?
Verificar si 1000 está dentro del rango RHS allowable. Si está dentro, la base no cambia pero se pierde beneficio. Si está fuera del rango, cambia la base (otro par de restricciones activas).

Dieta Alimenticia (Minimización)

Enunciado: Una persona necesita consumir mínimo: Vitaminas 800g, Proteínas 1900g, Sustancias Grasas 700g. Tiene 2 productos:

NutrienteProducto A (por paquete)Producto B (por paquete)Mínimo requerido
Vitaminas (g)1030800
Proteínas (g)30401.900
Grasas (g)3010700
Costo ($)2025MIN Z
1
¡Ojo! Este es un problema de MINIMIZACIÓN con restricciones ≥
En problemas de dieta, los nutrientes deben superar un mínimo (≥), no estar por debajo de un máximo. Las restricciones van al revés que en maximización. Esto cambia el tipo de variable: en vez de "holgura" hay superávit.
2
Modelo Matemático
Variables: x₁ = paquetes de A, x₂ = paquetes de B MIN Z = 20x₁ + 25x₂ Sujeto a: 10x₁ + 30x₂ ≥ 800 (Vitaminas) 30x₁ + 40x₂ ≥ 1900 (Proteínas) 30x₁ + 10x₂ ≥ 700 (Grasas) x₁, x₂ ≥ 0
3
Interceptos de cada restricción
Restricciónx₁=0 → x₂x₂=0 → x₁
Vitaminas (÷10)x₂ = 80x₁ = 80
Proteínas (÷10)x₂ = 47.5x₁ = 63.3
Grasas (÷10)x₂ = 70x₁ = 23.3
Diferencia clave con MAX: En minimización con ≥, la región factible está por encima y a la derecha de las rectas. El óptimo está en el vértice más cercano al origen.
4
Encontrar vértices por intersecciones
Vitaminas ∩ Proteínas:
10x₁+30x₂=800  (÷10)→ x₁+3x₂=80
30x₁+40x₂=1900  (÷10)→ 3x₁+4x₂=190
De (V): x₁=80−3x₂
3(80−3x₂)+4x₂=190 → 240−9x₂+4x₂=190 → −5x₂=−50
x₂=10, x₁=50
Verificar Grasas: 30(50)+10(10)=1600 ≥ 700 ✅
Proteínas ∩ Grasas:
30x₁+40x₂=1900 y 30x₁+10x₂=700
Restando: 30x₂=1200 → x₂=40
30x₁+400=1900 → x₁=50. Pero 30(50)+40(40)=1500+1600=3100 ≥ 1900 ✅
5
Evaluar Z en vértices
Vérticex₁x₂Z = 20x₁+25x₂
(0, 80) Vitaminas eje y080$2.000
Vit ∩ Prot ★5010$1.250
Prot ∩ Gras5040$2.000
(23.3, 0) Grasas eje x23.30$467
⚠️ El punto (23.3, 0) da Z=$467 pero hay que verificar que cumple TODAS las restricciones. Proteínas: 30(23.3)=699 < 1900 ❌ No es factible.
✅ Solución óptima: 50 paquetes A + 10 paquetes B = Costo mínimo $1.250
TP1b — Ej. 1

Raquetas CSD — Modelado con Restricción de %

Enunciado: CSD fabrica raquetas Estándar ($10/u) y Grande ($15/u). Datos para 2 semanas:

  • Aleación disponible: 80 kg (Estándar: 0.125 kg/u; Grande: 0.4 kg/u)
  • Tiempo manufactura: 80 hs totales (Estándar: 10 min/u; Grande: 12 min/u)
  • Condición: Estándar debe ser ≥ 20% de la producción total
1
Cómo modelar "al menos el 20%"
Esta es la restricción más complicada. "x₁ es al menos el 20% del total" significa:

x₁ ≥ 0.20 · (x₁ + x₂)

Expandimos: x₁ ≥ 0.20x₁ + 0.20x₂
Pasamos todo a un lado: x₁ − 0.20x₁ − 0.20x₂ ≥ 0
0.80x₁ − 0.20x₂ ≥ 0

O equivalente: x₁ ≥ 0.25x₂ (multiplicando por 5/4)
2
Modelo Completo
Variables: x₁ = raquetas Estándar, x₂ = raquetas Grandes MAX Z = 10x₁ + 15x₂ Sujeto a: 0.125x₁ + 0.4x₂ ≤ 80 (aleación) 10x₁ + 12x₂ ≤ 4800 (tiempo: 80hs × 60min) 0.80x₁ − 0.20x₂ ≥ 0 (mínimo 20% estándar) x₁, x₂ ≥ 0
3
Interpretación de las Variables de Holgura
VariableSignificado
s₁ (Aleación)Kg de aleación que sobran sin usar
s₂ (Tiempo)Minutos de manufactura sobrantes
s₃ (% mínimo)Exceso de raquetas estándar sobre el 20% requerido
4
Respuesta: ¿Cuánto pagaría por hora extra de manufactura?
El precio máximo a pagar por tiempo extra = Shadow Price de la restricción de tiempo.

Si SP = $X/minuto → pagaría hasta $X por cada minuto extra, porque ese minuto adicional genera exactamente $X de beneficio adicional.
Si SP = 0, la restricción de tiempo no está activa (hay holgura), y no tiene sentido pagar por más tiempo.
TP0 — Análisis

Sensibilidad — Usando los Resultados del TP0

El TP0 pide, habiendo hallado la solución óptima, responder preguntas de sensibilidad. Tomamos el problema del Práctico 1 de TP0 como base:

Solución Óptima (dada por TP0):
x₁ = 18, x₂ = 4, holguras s₁=0, s₂=0, s₃=22, Z = 700
A
Pregunta: "Modifique el problema para que adopte solución múltiple"
Hay solución múltiple cuando la Función Objetivo es paralela a una restricción activa. Eso pasa cuando la pendiente de la FO = pendiente de una restricción.

Si Z = c₁x₁ + c₂x₂, la pendiente es −c₁/c₂.
Ajustá c₁ o c₂ hasta que sea igual a la pendiente de una restricción activa. Así el óptimo "se extiende" por todo ese segmento.
B
Pregunta: "Si b₃ disminuye, ¿sobre qué recta se desplaza la solución?"
b₃ es el RHS de la restricción 3. Si cambia b₃, la recta de esa restricción se desplaza paralela a sí misma. Como la restricción 3 no está activa (s₃ = 22 > 0), el óptimo actual no está sobre esa recta. Mientras b₃ baje menos de 22, la solución no cambia. Si baja más, la restricción 3 se vuelve activa y la solución se mueve sobre la intersección de las otras dos restricciones activas.
C
Pregunta: "Si b₃ disminuye a 2 unidades, ¿cuál es la nueva solución?"
Con b₃ = 2, la tercera restricción se vuelve sumamente restrictiva. Habría que resolver el nuevo sistema completo. Si el vértice óptimo anterior viola la nueva restricción (verificar: s₃_nuevo = restricción − x₁°, x₂°), hay que buscar el nuevo vértice factible más cercano donde Z sea máximo.

🧠 Preguntas Teóricas — Hacé click para ver la respuesta

Intentá responder mentalmente antes de abrir cada una.

¿Qué son las variables de decisión en PL?
Son las incógnitas del problema: representan cuánto de cada cosa se decide hacer (producir, comprar, asignar). Se llaman x₁, x₂, etc. Siempre son ≥ 0 porque no tiene sentido producir negativos. En el enunciado suelen ser "la cantidad de X a fabricar".
¿Qué es la región factible y cómo se construye?
Es el conjunto de todos los puntos (x₁, x₂) que satisfacen todas las restricciones simultáneamente, incluyendo la no negatividad. Gráficamente es la intersección de todos los semiplanos definidos por las inecuaciones. Se construye graficando cada restricción como recta y sombreando el lado que cumple la desigualdad.
¿Por qué el óptimo siempre está en un vértice de la región factible?
Porque la función objetivo es lineal (una función lineal en un polígono convexo siempre alcanza su máximo/mínimo en un extremo, no en el interior). Al mover la línea Z = k alejándola del origen (en MAX), el último punto que toca la región factible antes de salir de ella es siempre un vértice.
¿Qué significa que una restricción tenga holgura = 0?
Que el recurso está completamente utilizado (saturado). El valor de la variable de holgura s = 0 indica que la solución óptima se encuentra exactamente sobre esa recta restricción. El Shadow Price de esa restricción será ≠ 0, lo que significa que si consiguiéramos más de ese recurso, el beneficio aumentaría.
¿Cuál es la diferencia entre una restricción ≤ y una restricción ≥?
≤ (menos o igual): Se usa para recursos con límite superior (no podés usar más de lo disponible). La holgura s ≥ 0 mide lo que sobra. Aparece en: horas máquina, kg de materia prima, presupuesto.

≥ (mayor o igual): Se usa para requisitos mínimos que deben cumplirse. La variable de superávit s mide cuánto se supera el mínimo. Aparece en: dietas (mínimos nutricionales), demanda mínima de producción.
¿Qué es el Shadow Price (precio sombra) y cómo se interpreta?
Es el incremento en el valor óptimo de Z que resulta de relajar en una unidad el RHS de una restricción activa. Si SP = $5 para la restricción de Horas-Máquina, significa que si conseguimos 1 hora más de máquina, el beneficio máximo aumenta en $5. Si SP = 0, la restricción no está activa y agregar más recurso no sirve de nada.
¿Qué significa "solución múltiple" en PL gráfico?
Ocurre cuando la función objetivo tiene exactamente la misma pendiente que una restricción activa. Gráficamente, la recta Z = k es paralela a un lado de la región factible, y "toca" todo ese segmento a la vez. El resultado es que cualquier combinación convexa de los dos vértices extremos del segmento es también una solución óptima con el mismo Z.
¿Cómo se modela una restricción del tipo "X debe ser al menos el p% del total"?
x₁ ≥ p · (x₁ + x₂)
Expandir: x₁ ≥ p·x₁ + p·x₂
Pasar todo a un lado: x₁ − p·x₁ − p·x₂ ≥ 0
Simplificar: (1−p)·x₁ − p·x₂ ≥ 0

Ejemplo con p=20%: 0.8x₁ − 0.2x₂ ≥ 0
¿Qué pasa cuando la región factible es vacía?
Si no existe ningún punto que satisfaga simultáneamente todas las restricciones, el problema es infactible. No tiene solución. Esto puede ocurrir cuando las restricciones se contradicen entre sí. En la práctica, suele ser señal de que hay un error en el modelado.
¿Qué significa que el Reduced Cost de una variable sea −5?
Significa que esa variable está fuera de la base (x = 0 en la solución óptima) y que para que valga la pena producirla, su beneficio unitario debería aumentar en $5. En otras palabras, es el costo de oportunidad de forzar la producción de esa variable.
¿Qué es el Rango Allowable del coeficiente de la FO?
Es el intervalo [mín, máx] dentro del cual puede variar el coeficiente c(j) de la función objetivo sin que cambie la base óptima (es decir, sin que cambie qué variables producen). Si el coeficiente sale del rango, el óptimo se mueve a otro vértice. Importante: el Z sí cambia aunque la base no cambie, porque la pendiente de la FO cambió.
¿Cómo decido si conviene contratar más horas de máquina a un costo extra?
Comparar el Shadow Price de esa restricción con el costo extra por unidad:
• Si SP > costo extra → conviene (cada hora adicional genera más beneficio de lo que cuesta)
• Si SP < costo extra → no conviene
• Si SP = costo extra → indiferente

Además verificar que la cantidad extra esté dentro del Rango Allowable del RHS, si no, habrá que recalcular el SP.
